\title{When Instance Normalization Hurts Energy Forecasting:\\
A Pre-Training Test for the Normalization Layer}

\author{Anonymous Author(s)}

\begin{document}
\maketitle

\begin{abstract}
On power grids, forecast errors for wind, solar, and load are absorbed by
fossil-fuelled reserves and curtailment; accuracy at ramps carries a direct
emissions footprint. Yet modern forecasters hand
the series \emph{level} to instance normalization (RevIN and successors), which
estimates it \emph{endogenously} from the target's own past. On wind, solar, and
load---whose level is set by weather observable in advance through archived
numerical forecasts---this discards recoverable signal, and no \emph{generic}
downstream capacity restores it. A pre-training test---the Level Predictability
Score (\lps)---flags this failure from covariates alone, before any model is
trained. In a pre-registered study (per-dataset predictions committed to version
control before any run) the test's sign is correct on all eight datasets, and on
all ten zones of a pre-registered wind-fleet disaggregation. Under information
parity---every model handed the same covariates---instance normalization is worse
in mean MSE than plain global scaling on all five backbones tested, confirming a
covariate-case conjecture recent work left open; conditioning the level on
covariates instead cuts day-ahead capacity-normalized error on a regional wind
fleet by $5\%$. Above
the threshold the remedy is a one-line change to the normalization layer, making
\lps{} a near-zero-cost screen for energy-forecasting pipelines.
\end{abstract}

\section{Problem and contributions}

Renewable generation and electricity demand are forecasting problems in which the
\emph{level} of the series is set by observable, physically grounded drivers.
Wind power follows the weather regime, photovoltaic output follows
cloud-modulated clear-sky geometry, and load follows temperature through a
degree-day relationship. In each case the level to be
predicted is largely exogenous and, in operations, observable in advance through
numerical weather prediction (NWP); the GEFCom2014 competition shipped
target-period ECMWF forecasts for its wind and solar tracks
\citep{hong2016gefcom}. Conditioning forecasts on these drivers is standard
practice, from the GEFCom competitions to operational wind and load models
\citep{hong2016gefcom,pinson2013wind}.

Modern deep forecasters, however, lead with instance normalization (RevIN;
\citealp{kim2022revin}), which removes each input window's mean and variance
before the backbone and restores them at the output; successors refine
\emph{which endogenous statistics} to use---slices \citep{liu2023san}, frequency
components \citep{ye2024fan}, learned coefficients \citep{fan2023dishts}---but
all estimate what they restore from the target's own recent past. On an exogenously
driven series the subtracted window mean is stale precisely when a weather ramp
or heat wave is about to move the level, and the staleness compounds with
horizon. For climate applications this is the common case: ramps and regime transitions
drive reserve scheduling and curtailment.

This default is now baked into covariate forecasters without being tested:
architectures built to ingest exogenous variables apply instance normalization to
the target channel and assume it helps, running no ablation against turning it off
\citep{wang2024timexer,crosslinear2025} (for TimeXer at code level: on by
default in the official implementation, unmentioned in the paper). Recent work questions the assumption---instance normalization
``discards potentially predictive context''---but only in the univariate,
covariate-free case, explicitly leaving ours open: ``a more general setting
would include \ldots exogenous covariates \ldots although we anticipate similar
conclusions, we do not consider it here'' \citep{role2026revin}.
Two adjacent lines stop short of this setting: pre-training normalization
selection from endogenous change-point statistics \citep{noise2025signal}, and
module-level benchmarking that conditions instance-normalization use on intrinsic
dataset properties \citep{timerecipe2025}---neither admits covariate-conditioned
level handling into the choice set; conditional normalization itself has prior
art \citep{gamakumara2023conditional}, but without the selection question.

We ask when this default helps and when it hurts, and reduce the answer to a
quantity computable before training. Our contributions are
(i)~an information-fair demonstration---the first controlled test of the covariate
case \citet{role2026revin} left as a conjecture---that the cost is a property of the
normalization \emph{layer}, not of covariate access (\S\ref{sec:results}); (ii)~a
pre-training diagnostic, the Level Predictability Score, with an explicit
decision rule (\S\ref{sec:score}); and (iii)~a pre-registered study---per-dataset
predictions committed to version control before any run---in which the rule is
correct on all eight datasets and all ten zones of a graded follow-up, the
pattern replicating across $4{,}202$ runs including state-of-the-art covariate
architectures (\S\ref{sec:results}). We do \emph{not} propose a new
normalizer: the conditional normalization we use to expose the boundary is itself
beaten by cheaper covariate-conditioned baselines---under our thesis consistent
evidence, not a weakness; the problem is the layer, not any one replacement.

\section{A boundary and a pre-training score}\label{sec:score}

Three ways to handle the level: global $z$-scoring (\rawm), instance
normalization (\inm), and covariate-conditional normalization (\cnm), which takes
the target-time level from a first-stage regression on covariates.
Writing any \inm{}-equipped backbone as
$\hat y = \bar y + s\, f\!\left((x-\bar y\mathbf 1)/s,\, g\right)$, its dependence on
the window mean $\bar y$ is additive with unit slope: the layer commits, before
seeing data, to a slope-one level response with no level--covariate
interaction---an irreducible cost whenever the window mean is a stale estimate of
the target-time level. A linear--Gaussian analysis makes the trade quantitative:
\inm{} pays the frozen statistic's within-horizon drift $s_x^2(h)+h\sigma_u^2$,
\cnm{} pays the covariate-unexplained level variance $(1-\lambda)V$, with
$\lambda\in[0,1]$ the exogenous predictability of the level; \cnm{} wins iff
$\lambda>\lambda^\star$, and $\lambda^\star$ falls with the horizon---multi-step
forecasting is where the endogenous default is most exposed (derivation in the
extended version).

$\lambda$ is unobservable before training, so we estimate it out of sample:
partition the training series into non-overlapping length-$w$ windows with means
$(\bar y_i, \bar x_i)$ and regress the former on the latter under expanding
chronological cross-validation, giving the \textbf{Level Predictability Score},
\begin{equation}\label{eq:lps}
\lps \;=\; 1 \;-\;
\frac{\sum_{k}\sum_{i\in\mathcal{T}_k}\bigl(\bar y_i-\hat g_k(\bar x_i)\bigr)^2}
     {\sum_{k}\sum_{i\in\mathcal{T}_k}\bigl(\bar y_i-\bar y^{\,\mathrm{tr}}_k\bigr)^2},
\end{equation}
the out-of-sample $R^2$ of window-mean levels on covariates ($\hat g_k$: LightGBM,
$w{=}96$, fit only on windows preceding block $\mathcal{T}_k$). The decision rule is one line:
$\lps \ge \tau \Rightarrow$ \emph{do not set the level endogenously}; otherwise
instance normalization ($\tau = 0.3$).
The threshold is anchored to the stylized crossover ($\approx0.28$ at $h{=}24$;
$0.27$--$0.28$ across horizons), conservative toward instance normalization;
above it, condition the level on covariates by whatever means the pipeline
supports (\S\ref{sec:results}).

\paragraph{Setup.} The pre-registered grid crosses five normalization arms
\{\rawm, RevIN, SAN, FAN, \cnm\} \citep{kim2022revin,liu2023san,ye2024fan} with
four backbones \{RLinear, PatchTST, SegRNN, LightGBM\}
\citep{li2023rlinear,nie2023patchtst,lin2023segrnn,ke2017lightgbm}, the horizons
of Table~\ref{tab:mini}, and five seeds, on eight datasets in two groups: four
exogenously driven energy series---Jeju Wind (self-curated from archived KMA
operational forecasts; the development dataset) and GEFCom-Wind/Load/Solar
\citep{hong2016gefcom} (third-party and confirmation-style, as are the four
standard LTSF benchmarks). NWP covariates
for the wind and solar sets are archived operational forecasts, never reanalysis;
GEFCom-Load uses the competition's realized station temperature, and Jeju Wind's
lead-matching is exact at $h{=}24$ while its $h{=}48$ cells inherit a day-ahead
band nominally valid to $h\le 24$---both disclosed in Limitations. Splits are
chronological and out-of-time; lookback is tuned on the RevIN arm and frozen
across arms---arms differ only in normalization (Appendix~\ref{app:setup}).

The dissociation is symmetric: \cnm{} is catastrophic on ETTh2 ($6.60$) because
its only covariates are calendar features with no exogenous level signal---the
first stage fits noise and the restore step injects it. The diagnostic pre-empts
exactly this failure (ETTh2's $\lps=-0.205$ sits well below $\tau$), which is why
the rule is one-sided.

\paragraph{It is the layer, not the information.} A natural objection: \cnm{}
wins only because it \emph{sees} the covariates. An information-fair block hands
every arm identical past and future covariates across five covariate-capable
backbones (Appendix~\ref{app:setup}). There the isolated cost of
the layer, $\mse(\text{RevIN}{+}\text{cov}) - \mse(\rawm{+}\text{cov})$, is
positive in the mean on all five and significant (95\% CI excluding zero) on four,
null on PatchTST-Cov: instance normalization is worse than plain scaling even
given the same covariates, because the restore step overwrites a level they carry.
The effect is small ($+0.004$ to $+0.024$ MSE)---the honest layer-only cost, one
to two orders below Table~\ref{tab:mini}'s headline gap, which measures access. The dissociation replicates on
TimeXer and iTransformer \citep{wang2024timexer,liu2024itransformer} (\cnm{} best
on all four exogenous datasets; mean RevIN$-$\cnm{} gap $+0.41$), while the
isolated RevIN-vs-\rawm{} toggle there is \emph{mixed}---dedicated covariate
pathways partly mask the layer, which is why the controlled generic-backbone
ablation is the right isolating instrument.

\paragraph{A strategy-level dissociation.} The same contrast holds across
\emph{strategies}, not one method: against seasonal-naive and climatology anchors,
three covariate-conditioned level models---a first-stage regression, a ridge
dynamic regression, and \cnm---beat the best instance-normalized arm on $11/12$
exogenous comparisons and $0/12$ standard ones ($10/12$ and $0/12$ under MASE);
every exception is the ridge dynamic regression (GEFCom-Load under MSE, plus
GEFCom-Solar under MASE).

\paragraph{The pre-training rule.} The official \lps{} and predicted gap sign
for each dataset were committed to version control before any grid run
(four minutes before the first run; Appendix~\ref{app:setup}); all
eight signs confirmed, unchanged under MSE, MAE, and MASE
(Fig.~\ref{fig:lpsgap}), and all eleven exogenous (dataset,\,$h$) Model
Confidence Sets retain \cnm{} alone (singleton in 20 of 23 cells on a single
path---a ranking consistent with the pairwise tests, not an uncertainty set). The classification is unchanged for any
$\tau\in[0.30,0.70]$; $\tau$ is anchored to the stylized crossover, not fitted
spacing.

\paragraph{A graded test within one family.} The eight datasets cluster into two
correlated regimes---$8/8$ is per-dataset evidence, not eight independent
successes---so we pre-registered a harder, graded test: GEFCom-Wind disaggregates
into ten zones of genuinely different NWP skill ($\lps$ $0.575$--$0.758$,
identical two-covariate structure), with per-zone $\lps$ and predictions
committed before any zone run. The sign rule holds in \emph{all
ten zones}, and the RevIN$-$\cnm{} gap widens with horizon ($0.53 \to 0.79 \to
0.90$ mean MSE at $h{=}24/96/336$), as the theory predicts. The gap's magnitude
trends \emph{positive} in \lps{} within this homogeneous family (Spearman
$+0.47$; narrow spread, $n{=}10$, $p{=}0.17$) while not tracking \lps{} across
the four heterogeneous datasets (Fig.~\ref{fig:lpsgap}): a validated regime
classifier, not yet a calibrated dial. (A pre-registered secondary, RevIN$-$\rawm{}$>0$ per zone
without covariates, is not confirmed---$4/10$; the small layer cost sits below
zone-level noise.)

\section{Implications for energy operations, and limitations}

The boundary is operational, and \lps{} needs only covariates and a first-stage
regression already in most pipelines---a near-zero-cost screen, seconds on a
CPU, before GPU-hours are spent. On Jeju Wind at the day-ahead horizon, conditioning the level
on covariates cuts capacity-normalized MAE from $0.105$ (RevIN, information-parity
linear mixer) to $0.100$ (\cnm, same mixer)---$5.0\%$ in the units an operator
sizes reserves in. The chain from forecast error to reserves to emissions is
established: sharper characterization of forecast uncertainty cuts reserve
requirements and system emissions in production simulation
\citep{sun2022mlreserve}; displaced fossil
generation carries $\approx0.5$\,tCO$_2$/MWh ($0.49$--$0.83$ across U.S.\ regions
and hours) \citep{kaffine2013emissions,silerevans2012marginal}.
As an \emph{illustrative} scale check---a $300$\,MW fleet, reserve proportional
to error---the $5\%$ reduction is of order a few thousand tCO$_2$/yr at full
displacement (less under part-load holding penalties): modest per installation,
scalable across fleets. This is not a dispatch
analysis---grid topology, unit commitment, and market structure are ignored (and
see Limitations on intervals); grid-specific figures belong to the cited tools.
Above the threshold, the replacements are close ($0.29/0.16/0.14/0.06$ MSE for a
first-stage regression vs $0.29/0.16/0.11/0.06$ for \cnm)---choose by pipeline
fit; the cheapest deep-stack drop-in feeds the backbone the first-stage level in
place of the window mean (classical analogue: regression with ARIMA errors, not
benchmarked here).

\paragraph{Limitations.} Two provenance caveats bound the exogenous numbers:
GEFCom-Load's covariate is \emph{realized} (not forecast)
temperature---attainable, not operational, skill---and Jeju Wind's $h{=}48$
cells consume a band valid to $h\le24$, so pooled Jeju figures are optimistic;
the day-ahead figure above avoids both. The boundary
transfers to pinball loss (\cnm{} best on all four exogenous sets) but \cnm{}
\emph{under-covers} its intervals ($0.50$--$0.66$ at nominal $0.80$; first-stage
uncertainty unpropagated): post-hoc recalibration is the natural remedy (not yet
run); reserve sizing is a quantile decision, so the emissions check reads from
the point-forecast gain only. Evaluation uses one chronological origin (a
validation-segment second origin reproduces the four exogenous signs); rolling
origins and datasets in the empty \lps{} gap ($0.28$--$0.58$) come next.

\section{Setup details, accounting, and availability}\label{app:setup}

\paragraph{Data and splits.} Hourly resolution throughout. Exogenous group: Jeju
Wind (self-curated from archived KMA operational forecasts, lead-matched at
$h{=}24$; development dataset) and GEFCom2014 Wind/Load/Solar
\citep{hong2016gefcom} (competition-provided target-time forecast covariates for
wind and solar; realized station temperature for load). Standard group: ETTh1,
ETTh2, Electricity, Weather under literature splits (ETT 12/4/4 months; 7:1:2
elsewhere); zone series use chronological 60/20/20. Global $z$-scoring is fit on
the train segment only; splits are strictly out-of-time.

\paragraph{Run accounting.} Main grid $1{,}794$ runs: 5 arms $\times$ 4 backbones
$\times$ $h\in\{24,96,336\}$ (Jeju Wind $\{24,48\}$, set by forecast-band
coverage---hence \emph{eleven} exogenous (dataset,\,$h$) cells) $\times$ 5 seeds;
LightGBM$\times$\{SAN, FAN\} is structurally inapplicable (torch statistics
predictors). Information-parity block $1{,}133$ runs over five covariate-capable
backbones: LightGBM-Cov, linear mixer, MLP mixer, SegRNN-Cov, PatchTST-Cov, every
arm given identical past and future covariates. SOTA replication $1{,}275$ runs
(TimeXer, iTransformer; built-in normalization removed, arms injected). Total
$4{,}202$. The graded zone study adds $450$ pre-registered RLinear runs (10 zones
$\times$ 3 arms $\times$ 3 horizons $\times$ 5 seeds); a deferred LightGBM arm is
incomplete and excluded from the primary endpoint, disclosed at pre-registration
analysis time.

\paragraph{Inference.} Information-parity confidence intervals are cluster
bootstraps over the eleven seed-averaged (dataset,\,$h$) cells. The Model
Confidence Set is computed at $\alpha=0.10$ per (dataset,\,$h$) on
backbone-averaged squared-error series; survivor sets are stable across bootstrap
seeds. All standard-group loss series are segment-aware (no windows across curated
gaps).

\paragraph{LPS protocol.} Non-overlapping windows of length $w=96$; first stage
LightGBM under expanding chronological cross-validation, fit only on windows
preceding each evaluation block (Eq.~\ref{eq:lps}); $\tau=0.3$ was fixed at
pre-registration together with the per-dataset sign predictions. The main-grid
pre-registration commit precedes the first grid run by four minutes; the zone
study's per-zone \lps{} values and predictions were likewise committed before any
zone run. Both are timestamped in the repository below.
